# system-install.el

This is a simple package which provides handy wrappers around pacman / apt / dnf and enables
installation / removal / upgrade of packages using a unified, completing read interface.

Package lists are cached in a json file which defaults to =~/.emacs.d/system-package-cache.json=, but can be customized by setting the value of ~system-install--package-cache-file~.

The json file will be refreshed at a default interval of 7 days, which can be changed by setting =system-install--cache-refresh-days=.

Commands:

#+begin_src
(system-install)
(system-install-upgrade)
(system-install-update)
(system-install-package-info)
(system-install-remove-package)
(system-install-upgrade-package)
(system-install-clean-cache)
(system-install-auto-refresh)
#+end_src

** Privileged commands

Commands that need root are run through ~sudo~ (see ~system-install-sudo-command~) in a
[[info:emacs#Interactive Shell][comint]] buffer, so ordinary prompts such as =Proceed with installation? [Y/n]= can be
answered in place.

The buffer kills itself once the command exits, restoring whatever its window was showing
beforehand. Set ~system-install-kill-buffer-when-finished~ to ~on-success~ to hold on to
the buffer of a command that failed, or to ~nil~ to always keep it; press =q= to bury a
buffer that is kept. ~system-install-package-info~ is exempt, since its output is the
point of the command.

Password prompts are read through ~read-passwd~ in the minibuffer and are never echoed
into the buffer. Detection matches against a rolling tail of recent output rather than a
single chunk of it, so a prompt that arrives split across several reads is still
recognized; ~SUDO_PROMPT~ is additionally pinned to ~system-install-sudo-prompt~ so that
detection does not depend on the locale or on the sudo implementation in use.
